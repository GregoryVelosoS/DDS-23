Display no CSS

Entenda como os elementos ocupam espaço, se posicionam e se organizam na página.

O que é display?

A propriedade display define como um elemento participa do layout da página. Dependendo do valor utilizado, o elemento pode ocupar uma linha inteira, permanecer na mesma linha de outros elementos ou organizar seus elementos filhos de diferentes maneiras.

Os principais tipos

Veja o comportamento de cada valor e quando ele pode ser utilizado.

01 display: block

Block

O elemento normalmente começa em uma nova linha e ocupa a largura disponível do seu contexto.

Quando usar?

Seções, títulos, parágrafos, containers e outros elementos que devem ficar em linhas separadas.

02 display: inline

Inline

O elemento permanece no fluxo da mesma linha, junto de outros elementos inline.

Quando usar?

Trechos de texto, links e pequenos elementos que precisam permanecer dentro da mesma linha.

03 display: inline-block

Inline-block

Combina características de inline e block: os elementos ficam na mesma linha, mas permitem definir dimensões.
