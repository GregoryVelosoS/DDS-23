Display na prática

Observe como os mesmos elementos se comportam quando alteramos a propriedade display.

Antes de começar

A propriedade display determina como um elemento participa do layout da página.

Nesta atividade vamos utilizar os mesmos elementos em diferentes situações para observar as mudanças no comportamento do layout.

01

display: block

Os elementos ocupam uma nova linha.

display: block;
HTML
CSS
JAVASCRIPT
Observe: Cada elemento começa em uma nova linha.
02

display: inline

Os elementos permanecem no fluxo da mesma linha.

display: inline;
HTML CSS JAVASCRIPT
Observe: Os elementos ficam lado a lado e continuam participando do fluxo de texto.
03

display: inline-block

Os elementos ficam na mesma linha, mas aceitam dimensões.

display: inline-block;
HTML
CSS
JAVASCRIPT
Observe: Os elementos ficam lado a lado, mas podemos controlar largura e altura.
04

display: flex

O elemento pai se torna um flex container.

display: flex;
HTML
CSS
JAVASCRIPT
Observe: Agora conseguimos controlar o posicionamento dos elementos filhos usando propriedades do Flexbox.
flex-direction Define a direção dos elementos.
justify-content Controla o alinhamento no eixo principal.
align-items Controla o alinhamento no eixo transversal.
gap Define o espaço entre os elementos.

08

Qual display escolher?

Não existe um único display correto. A escolha depende do comportamento desejado para o elemento.

block

Um elemento abaixo do outro

Útil para estruturas que ocupam uma nova linha.

inline

Elementos no fluxo do texto

Útil para pequenos conteúdos que permanecem na mesma linha.

inline-block

Lado a lado com dimensões

Permite combinar características de inline e block.

flex

Organização em uma dimensão

Excelente para organizar elementos em linha ou coluna.

grid

Organização em duas dimensões

Indicado para estruturas baseadas em linhas e colunas.
